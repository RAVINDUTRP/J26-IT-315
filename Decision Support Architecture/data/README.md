# Component 04 Data Directory

This directory stores datasets for the **AI-Based Disaster Decision Support Framework**:

- `raw/`: Stores `synthetic_disaster_scenarios.csv`, containing synthetic disaster scenarios generated under controlled environmental and socio-technical distributions with transparent labeling policies.
- `processed/`: Stores `train_scenarios.csv`, `test_scenarios.csv`, and `data_dictionary.csv`.

### Scientific Integrity Notice
These scenarios are synthetically generated for algorithm verification, sensitivity testing, and multi-class prioritization benchmarking. They do not represent real-world civil protection disaster records.
